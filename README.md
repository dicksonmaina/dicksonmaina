## 🚀 What I'm Building

### [kilo-auto-debug](https://github.com/dicksonmaina/kilo-auto-debug)
**Self-improving debugging memory for AI coding agents**
- Redis-backed bug/fix memory with circuit breaker safety
- Lightweight local Ollama MCP for fast AI suggestions (`qwen2.5:3b`)
- Agent rules that prevent infinite loops and auto-revert failed fixes
- Background learner that analyzes patterns and improves over time

### [nexus-ecosystem](https://github.com/dicksonmaina/nexus-ecosystem)
**NEXUS knowledge graph ingestion pipeline**
- AI embedding + multi-source data fusion
- Automated paper curation from arXiv
- Graph-based memory for long-running agents

### [jarvis-agile](https://github.com/dicksonmaina/jarvis-agile)
**JARVIS AI agent — multi-provider, multi-channel**
- Python/Flask backend with WhatsApp, Telegram, Redis
- Multi-provider LLM support (Ollama, OpenAI, Anthropic, etc.)
- Designed for always-on autonomous operation

### [claw-code](https://github.com/dicksonmaina/claw-code)
**AI development agent with MCP support**
- Rust-native performance with behavioral parity harness
- MCP server integrations for tools, filesystem, and memory
- Built for reliability and low resource usage

### [career-ops](https://github.com/dicksonmaina/career-ops)
**Automated job application pipeline with AI learning**

### [openwa](https://github.com/dicksonmaina/openwa)
**Open Source WhatsApp API wrapper**
- Full-stack NestJS application
- Production-grade WhatsApp integration

## 🧠 My Philosophy

1. **Code is information** — the system can upgrade itself if it can read and write code
2. **No crash is acceptable** — circuit breakers, pre-flight checks, and auto-revert are non-negotiable
3. **Learning is mandatory** — every bug, fix, and pattern must be stored and reused
4. **Free and open** — build with free models, open tools, and zero vendor lock-in
5. **Speed matters** — lightweight models, fast responses, no bloat
